#  Recetas Para Flojos

¡Bienvenido al rincón donde cocinar rico no cuesta trabajo! Un recetario web estructurado para practicar maquetación web, responsive design y despliegue en GitHub Pages.

 **[Ver Proyecto En Vivo](https://recetasparaflojos.github.io/recetas-para-flojos/)**

---

##  Contenido del Recetario

Actualmente el sitio cuenta con las siguientes recetas fáciles y rápidas:
-  **Schnitzel** (Pollo empanizado crujiente)
-  **Arroz con Huevo** (El salvavidas clásico)
-  **Mac and Cheese** (Cremosos y reconfortantes)
-  **Chimichangas** (Doraditas y crujientes)
-  **Chocotorta** (Postre frío sin horno)

---

##  Tecnologías Utilizadas

- **HTML5** (Estructuración semántica)
- **GitHub Pages** (Despliegue y hosting gratuito)
